19 October 2026. ## Design

- Pages use the existing Albion templates. Add the retained home, Hawthorns, competitive results/rivalries and wartime pages, preserving current URLs, anchors, scripts, fallback HTML and source links.
- Give original page sections named plain-text/link fields backed by developer-owned markup templates. No raw HTML editor. Extract duplicate dynamic era/exhibit content into the existing generated museum component with editable Eras, Exhibits, Sources and Photographs collections; the generator remains authoritative for cards/readers/related links.
- Match JSON/CSV, saved result rows, calculations, evidence status and current-feed protections remain outside the casual CMS fields. Page introductions, rivalry stories and research explanations are editable. Archive corrections retain the checked research update path.
- Add responsive Section blocks with one to three columns, supported navy/white/light-blue backgrounds, bounded spacing, and simple text/photograph/link blocks. Keep the visual system and mobile stacking.
- Add Page templates as a content collection. A shared layout widget wraps the existing block picker, supports copying a page layout into a named template and applying published templates to new pages. Copies are independent; editing a template never silently changes an existing page. Template saving and publication use the same protected draft/preview workflow, with no custom credential or backend write shortcut.
- Keep the existing shared blue-vinyl fact compatible. Global navigation, artwork metadata and quiz content must have a clear editorial source. Preserve credits and distinguish modern fan artwork from archive photographs.
